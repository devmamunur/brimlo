# Game-picking checklist

Score every game before you plan a video. Record it only if it passes **all "Must"** and **at least 3 "Strong"**.

## Must (all)

- [ ] Incremental / idle / clicker / survivor-like / tower-defense game, **or a satisfying job-sim with upgrades** (cleaning, restoring, junkyard, mining…), on **Steam or itch.io** (itch.io HTML5 browser games run on the Mac with no CrossOver). Not Roblox, not mobile, not a fan game with someone else's brand.
- [ ] **Run check passed:** your own 10-minute test in **CrossOver Steam** worked (launch, one upgrade loop, smooth, OBS capture). CrossOver Steam is the main way; Mac Steam only if it is smoother. Windows-only is fine. No anti-cheat.
- [ ] Numbers or the world **visibly grow** on screen.
- [ ] It fits **one video**. No Part 2.
- [ ] The developer allows videos and monetization (Steam page, press kit, or Discussions; email if unsure).

## Strong (at least 3)

- [ ] **New:** demo, playtest or launch in the last 10 days, or coming soon.
- [ ] The idea fits in **one strange sentence** ("rats eat a city", "feed an AI").
- [ ] Hot theme: dark/horror · swarm/army from nothing · cozy cleanup · mining/digging/fishing.
- [ ] You can **100% it** in one 3–4 h session.
- [ ] Idle Cub, Dex and MOREQUIS have **not** covered it yet, and **no English video has 10K+ views** — or you have a clearly different angle.
- [ ] **Simple everyday idea** anyone gets in one second (emails, coins, dust, leaves, carrots). These were Ridiculously Random's hits (study 25 Oct 2026).
- [ ] A clear thumbnail exists: before/after or a giant number.

## Money

- [ ] Free (demo / playtest / F2P / key)? → good.
- [ ] Paid? → on sale, and this month's total stays under $15.

## Mac test (10 minutes)

1. **Start in CrossOver Steam** (the main way, Mamunur 25 Oct 2026: it often runs smoother than Mac Steam; Seabun failed on Mac Steam but runs in CrossOver). Use Mac Steam only if CrossOver has problems.
2. Problems in CrossOver? Check the CodeWeavers compatibility DB for tips.
3. CrossOver → Windows Steam → install → launch.
4. Play one upgrade loop. Check sound and mouse.
5. OBS: is the game window captured? Is the mic on its own track?
6. **Game crashes on launch?** CrossOver → Quit All Applications → Bottle → Graphics: try **DXMT** (fixed I Am Plague), then D3DMetal, DXVK, WineD3D. Max 30 minutes, then drop it.
7. Pass → write "CrossOver ✅ [date] + graphics mode" in [backlog.md](backlog.md). Fail → write ❌ and why.

### Extra rules for sim games

- [ ] **Progression test:** after 10 minutes, do you have upgrades, new tools or growing numbers? If not → skip (plain sims go on the one-video list).
- [ ] Can you reach a clear **end or 100%** in 3–4 hours (or does it have a natural "best 2–3 hours" cut)?
- [ ] Is there a **big goal for the title** ("clean the whole world", "spend $1 billion", "find the bitcoin")?
- [ ] Not more than 2 sim videos in a row — mix with classic incrementals (target ~60% incremental / 40% sim).
