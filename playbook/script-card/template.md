# Script card template

The format for every Brimlo recording script. `/script` and `/new-video` copy this into the video file's "Recording script" section and fill it for one game.

- Filled examples (approved by Mamunur): [examples/](examples/). Copy their **shape and English level**, never their lines or jokes.
- Rules: [../hooks-and-scripts.md](../hooks-and-scripts.md) ("The start: Reason → Goal → Go", "The loop", "Simple words").
- Format approved Fri 6 Nov 2026. Start, first 2 minutes and subscribe line updated Thu 19 Nov 2026 ([5-minute study](../../research/reports/2026-11-19-first-5-minutes/README.md)).

## How to fill it

1. **Research first.** Learn the game from real play: `brimlo_steam_game` / `brimlo_steam_reviews`, and **1–2 YouTube transcripts** of the game (`brimlo_video_transcript`, free). Write the facts and the timing table in the video file, above the script (see "Research block" at the bottom).
2. **Simple English.** A learner (A2–B1) must understand every word. Max ~10–12 words per line. One idea per line. Present tense for what happens now; "will" for the future ("At the end, his roots will be everywhere"), never present tense for a future thing. Plain action words (water, food, grow, coins) instead of game jargon. **This is for the whole file** — game facts, notes, tables and research too, not only the spoken lines. Example: "grow a root", never "shoot a hypha".
3. **Friends, not a presentation.** full casual sentences with "I", "we" and "you" (the hero is always "I", never a named character); small reactions ("Oh no.", "Nice!", "Wait…", "Hmm."); little opinions ("I love it."). No slogan fragments ("Start to end, in one video." ✗), no announcing lines ("In this video we will…" ✗), no formal words. Read each line after the line before it: would a friend say it like that? Tense: now = present, later/end = "will" / "going to", done = past.
4. **True to the game.** Every line must fit something that really happens. Use `[X]` for numbers he reads from the screen.
5. **New every video.** New story, new joke. The hero is always "I" (Mamunur, 8 Nov 2026). Check the last 3 video files.
6. Replace every `[ … ]` and every *italic note*. Delete notes that don't apply.

## Recording script

Simple words only. Short lines. Say them slowly. Small mistakes are fine.

### The story of this video

*3–5 short lines. Me, a silly reason, a big end. Always first person: I am the one in the game. No named character (Mamunur, 8 Nov 2026). The reason here becomes Line 1 of the start.*

[Silly thing that happened to me]. So I have to [goal with a number]. Right now I have [tiny tool]. At the end, [big result]. Calm and kind.

### Words you will use (with Bangla)

*12–20 words he will say: game resources, actions, objects, animals/enemies, the game name. Explain a game word in a few words.*

| Word | Bangla | Say it like |
|---|---|---|
| [word] | [বাংলা] | [easy sound, e.g. HEJ-hog] |
| [game word] ([what it is, 3–6 words]) | [বাংলা] | [sound] |
| [Game name] | — | [sound] |

### Before you press record

1. Check the game is in your Steam library / the demo is installed. Play it in CrossOver for 10 minutes.
2. Start a **new save**. [Naming screen: type **[Name]**.] Do this **before** OBS.
3. Set graphics, sound and language now.
4. Start OBS when [first gameplay screen] is on screen.
5. **Don't read the help text** or the store page. Just do it.
6. Know your **first upgrade** (from the test play). Buy it before 1:30. Say its name once, then buy.
7. Take screenshots: [start], [first big moment], [each goal], [the end].

### The start: Reason → Goal → Go (0:00–0:15)

*3 lines. Say them while you already play. Start the first action on line 2. Never "This is the game named…", never a tour. A new reason every video. Ideas: [../hooks-and-scripts.md](../hooks-and-scripts.md) → "Reason ideas". If no story fits, use the backup: goal + number.*

| Time | On screen | Say |
|---|---|---|
| 0:00 | [Start screen, me / my tiny tool] | **Line 1 — reason:** "[Silly thing that happened to me]." |
| 0:04 | **[First action: click / dig / drink]** | **Line 2 — goal:** "So, [to do X], I have to [goal with a number]." |
| 0:09 | [Still doing the action] | **Line 3 — journey + go:** "Right now I have [tiny tool]. [Big thing later]. Let's get [verb]-ing." |

### First loop (0:15–1:30)

Do → say the number → first upgrade → test it. Something new every 15–20 seconds.

| When | Do | Say |
|---|---|---|
| First [resource / money] | [action] | "[X]. [short reaction]" |
| **First upgrade (before 1:30)** | buy it | "[Upgrade in 2–3 words]. [What it does, simple]. Buying it." |
| Test it | [action again] | "Before: [X]. Now: [Y]. Much better." |
| First [blocker] | [what stops you] | "Oh no, [it]. I can't [do it]. …Not yet." |
| First [bonus event, from the timing table] | [action] | "[short excited line]" |
| If [bonus event] is late | [keep doing the main action] | "[calm filler line]" |

"Not yet" is a small promise. Later you pay it off with "Remember…?" (big moments table). This keeps people watching.

### The loop (1:30 → end)

do → number → choose upgrade + **why** → buy → test → before/after → remind the goal. A short reaction every 20–30 s.

- Goal reminder for this game: "[Still X to go / one day this will be Y]."

### Subscribe line (after the first big upgrade, ~5–10 min, never in the first 5 min)

> "Want to see [how big I get / if I can do X]? Subscribe and stay with me."

*Keep it this short. No upload-plan sentence ("I finish a new game every few days" ✗).*

### Running joke: [one-line name of the joke]

*From this game's real events (an enemy, a rival, a strange rule). Say only what happens on screen.*

- [First time it happens]: "[line]"
- [It happens again]: "[line]"
- [It goes wrong]: "[line]"
- [You win against it]: "[line]"
- Late game: "[line]"

Use it 4–5 times, not more. Don't reuse: [jokes from the last 3 videos].

### Score lines (say the real number)

- "I'm at [X] [unit] now." (*the counter at [place on screen]*)
- "We need [Y]. We're at [X]. Getting close."
- "That's [X] [things]. Only [Y minus X] more to find."

### Lines for big moments (with your real numbers)

*12–16 rows, named after this game's real mechanics.*

| Moment | Say |
|---|---|
| First points / money | "[line]" |
| First upgrade (say it short) | "[Upgrade in 2–3 words]? Yes, I'm buying that. [Effect in simple words]." |
| New area | "[line]" |
| [Main building / helper] | "[line]" |
| [Pay off "Not yet" #1] | "Remember that [thing] from the start? Watch this. Now I can [do it]." |
| [Pay off "Not yet" #2] | "Remember the [thing]? Well… now I [do it]." |
| First [big goal item] | "Wait, wait… yes! [Thing]! That's one. [Y minus 1] more to find." |
| Before and after | "You know, at the start [small] was a big deal. Now I have [X]." |
| Last goal | "That's all [Y]! I can't believe it. I'm the boss of [place] now." |
| Slow part | "This part is the same. Let me skip ahead a bit." (speed up or cut) |

### Thinking out loud

- "Hmm, [choice A] or [choice B]? I think I need [A] more."
- "[Left/right] has more [resource], but look, there's [problem]. Let's go [other way] first."
- "I'll do more [X] first. Then [Y]."

### Ending (last 1–2 minutes)

> "And that's it! I was just [tiny start]. And look at me now. [Result with numbers]."
> "My favorite part? [X]. [Why, in one short line.]"
> "If you like calm games where something small gets really big, you'll like this one."
> "Thanks for watching. See you next time."

*Keep only these 4 lines. Good part only — no bad part, no price or link, no joke close, no "which game next?" question, no tagline (Mamunur, 6 Nov 2026).*
