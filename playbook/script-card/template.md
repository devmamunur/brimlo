# Script card template

The format for every Brimlo recording script. `/script` and `/new-video` copy this into the video file's "Recording script" section and fill it for one game.

- Filled examples (approved by Mamunur): [examples/](examples/). Copy their **shape and English level**, never their lines or jokes.
- Simple-word rules: [../hooks-and-scripts.md](../hooks-and-scripts.md) → "Simple words".
- Format approved Fri 6 Nov 2026.

## How to fill it

1. **Research first.** Learn the game from real play: `brimlo_steam_game` / `brimlo_steam_reviews`, and **1–2 YouTube transcripts** of the game (`brimlo_video_transcript`, free). Write the facts and the timing table in the video file, above the script (see "Research block" at the bottom).
2. **Simple English.** A learner (A2–B1) must understand every word. Max ~10–12 words per line. One idea per line. Present tense. Plain action words (water, food, grow, coins) instead of game jargon.
3. **True to the game.** Every line must fit something that really happens. Use `[X]` for numbers he reads from the screen.
4. **New every video.** New hero name, new story, new joke. Check the last 3 video files.
5. Replace every `[ … ]` and every *italic note*. Delete notes that don't apply.

## Recording script

Simple words only. Short lines. Say them slowly. Small mistakes are fine.

### The story of this video

*3–5 short lines. A small hero, a small problem, a big end. If the game lets you name something, give it a funny human name (never "Brimlo").*

[Hero] is [tiny thing]. [Problem: who/what is against him]. [Hero] is small, but he wants to be big. At the end, [big result]. Talk about [Hero] like a small friend. Calm and kind.

### Words you will use (with Bangla)

*12–20 words he will say: game resources, actions, objects, animals/enemies, the game name. Explain a game word in a few words.*

| Word | Bangla | Say it like |
|---|---|---|
| [word] | [বাংলা] | [easy sound, e.g. HEJ-hog] |
| [game word] ([what it is, 3–6 words]) | [বাংলা] | [sound] |
| [Game name] | — | [sound] |

### Before you press record

1. Check the game is in your Steam library / the demo is installed. Play it in CrossOver for 10 minutes.
2. Start a **new save**. [Naming screen: type **[Name]**.] Do this **before** OBS.
3. Set graphics, sound and language now.
4. Start OBS when [first gameplay screen] is on screen.
5. **Don't read the help text** on screen. Just do it.
6. Don't open the upgrade menu in the first 2 minutes.
7. Take screenshots: [start], [first big moment], [each goal], [the end].

### Cold open (optional, for `/hook` after the edit — max 10 s)

Show the end: [late-game picture].
Voice-over: "This was [tiny start]. [Time] later… [result]."

### First 10 seconds (say this while you already play)

| Time | On screen | Say |
|---|---|---|
| 0:00 | [Point the mouse at the hero / start object] | "This is [Hero]. [Hero] is [tiny thing]." |
| 0:03 | **[First action: click / dig / shoot]** | "[The goal with a number from this game.]" |
| 0:07 | [What changes on screen] | "[The big dream in one line.]" |

### 0:10 – 0:30

> "Right now, [Hero] is very small. At the end of this video, [result]. Start to end, in one video."
> ([Action again.]) "[The main cost or rule in one sentence.] Let's go, [Hero]."

### First 2 minutes (keep moving)

Do something new every 15–20 seconds. Say one short line.

| When | Do | Say |
|---|---|---|
| First [resource] | [action] | "[short line]" |
| First [build / buy] | [action] | "[short line]" |
| First [blocker] | [what stops you] | "[It]. [Hero] can't [do it]. Not yet." |
| First [thing you can't use yet] | [see it] | "[Thing]. We don't [use it]. …Not yet." |
| First [bonus event, from the timing table] | [action] | "[short excited line]" |
| If [bonus event] is late | [keep doing the main action] | "[calm filler line]" |
| ~2:00 | [keep playing] | Subscribe line (below) |

"Not yet" is a small promise. Later you pay it off with "Remember…?" (big moments table). This keeps people watching.

### Subscribe line (~2:00)

> "Do you want to see how big [Hero] gets? Subscribe. I finish a new game every few days."

### Running joke: [one-line name of the joke]

*From this game's real events (an enemy, a rival, a strange rule). Say only what happens on screen.*

- [First time it happens]: "[line]"
- [It happens again]: "[line]"
- [It goes wrong]: "[line]"
- [You win against it]: "[line]"
- Late game: "[line]"

Use it 4–5 times, not more. Don't reuse: [jokes from the last 3 videos].

### Score lines (say the real number)

- "[Hero] is [X] [unit] now." (*the counter at [place on screen]*)
- "The goal is [Y]. We have [X]."
- "[Thing]: [X] out of [Y]. Next: number [X+1]."

### Lines for big moments (with your real numbers)

*12–16 rows, named after this game's real mechanics.*

| Moment | Say |
|---|---|
| First points / money | "[line]" |
| First upgrade (say it short) | "[Upgrade in 2–3 words]. I buy it. [Effect in simple words]." |
| New area | "[line]" |
| [Main building / helper] | "[line]" |
| [Pay off "Not yet" #1] | "Remember the [thing]? Now [Hero] [does it]." |
| [Pay off "Not yet" #2] | "Remember that [thing]? Now [Hero] [does it]." |
| First [big goal item] | "[Thing]! One out of [Y]." |
| Before and after | "At the start, [small]. Now I have [X]." |
| Last goal | "[Y] out of [Y]! [Hero] is the boss of [place] now." |
| Slow part | "This part is the same. Let me skip ahead a bit." (speed up or cut) |
| Waiting | "Okay. Slowly. [Hero] is [working]. We'll get there." |

### Thinking out loud

- "[Choice A] or [choice B]? I need [A] more."
- "[Left/right] has more [resource], but there is [problem]. Let's go [other way] first."
- "More [X] first. Then [Y]."

### Ending (last 1–2 minutes)

> "So that's [Game]. [Hero] was [tiny start]. Now [result with numbers]."
> "The best part is [X]. The bad part is [your honest answer]."
> "If you like calm games where small things get big, try this one. It's [only a few dollars / a free demo] on Steam. The link is in the description."
> "[Close the joke/story in one line.]"
> "Thanks for watching. Which game should I play next? Tell me in the comments. You rest. I'll keep going. See you next time."

### Practice lines (say each 3 times before recording)

1. [First line of the video]
2. [Second line]
3. [Third line]
4. [Hardest "Not yet" line]
5. [Bonus-event line]
